# NuxtAnuncios
## Comandos
- /anunciar (Permissão: anuncios.usar).
- /anuncio cancelar (Permissão: anuncios.usar).
- /nuxtanuncios reload (Permissão: anuncios.admin ou OP).
## Funcionalidades
- Suporta diversos plugins de Economias (yEconomy, NextEconomy, PlayerPoints, etc).
- Funciona da 1.8 até a 26.X.
- Plugin totalmente feito em Menus.
- Plugin totalmente configurável.
- Funciona com SQLite de forma extremamente otimizada.

## Dependências
- Vault
- Algum plugin de Economia ou Pontos (Priorize utilizar o PlayerPoint)
